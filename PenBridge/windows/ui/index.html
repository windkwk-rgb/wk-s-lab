태블릿

USB나 무선 디버깅으로 연결된 태블릿에 앱을 설치하고 관리해요.

연결된 기기
연결된 태블릿이 없어요 케이블을 꽂고 태블릿에서 USB 디버깅을 허용해 주세요.
처음 연결할 때
  1. 설정 → 태블릿 정보에서 빌드번호를 7번 눌러요
  2. 개발자 옵션에서 USB 디버깅을 켜요
  3. 케이블을 꽂고 태블릿의 허용을 눌러요 (항상 허용 추천)
  4. 목록에 나타나면 태블릿에 설치를 눌러요
안 보이면 충전 전용이 아닌 데이터 케이블인지, 제조사 USB 드라이버가 필요한지 확인해 주세요.
