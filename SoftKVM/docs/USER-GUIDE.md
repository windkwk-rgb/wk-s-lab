# PC 마우스·키보드 공유 (Windows → Mac / Android)

윈도우에 꽂힌 마우스·키보드 하나로 같은 와이파이의 맥과 안드로이드를 조작합니다.
커서를 화면 가장자리로 밀면 옆 기기로 넘어가고, 반대쪽으로 밀면 돌아옵니다.

배치는 서버의 **화면 배치 창**에서 기기 상자를 끌어서 정합니다.

## 1. 윈도우 (서버)
```
pip install pynput pyperclip pystray pillow pywebview
python windows\server.py        (콘솔 창 없이 쓰려면 pythonw)
```
- 실행하면 **화면 배치 창**과 트레이 아이콘이 뜹니다.
  - 연결된 기기는 초록 상자로 나타납니다. 끌어서 윈도우 화면 상하좌우 어디든 붙이세요.
  - 노란 선 = 실제로 넘어가는 구간. 상자를 위아래로 밀면 그 구간이 바뀝니다 (예: 폰을 오른쪽 아래 구석에).
  - 상자 위에서 휠 = 상자 크기 조절 (넘어가는 구간 길이가 달라짐).
  - 바꾸면 즉시 적용·자동 저장. 창을 닫으면 트레이로 숨고, 트레이 아이콘 더블클릭으로 다시 열기, 우클릭 → 종료.
  - 폰을 가로로 돌리면 상자도 자동으로 가로가 됩니다.
- 처음 실행하면 `config.json`이 생깁니다. **`key`(비밀번호)를 꼭 바꾸세요.** 키 입력이 네트워크로 전송되므로, 비밀번호를 아는 기기만 연결됩니다. (암호화는 되지 않으니 공용 와이파이에서는 쓰지 마세요.)
- 실행하면 `192.168.x.x:24800` 같은 주소가 출력됩니다. 이 IP를 맥·안드로이드에 입력합니다.
- 방화벽 허용 창이 뜨면 "개인 네트워크" 허용.
- **Scroll Lock** = 언제든 윈도우로 강제 복귀.
- 관리자 권한 프로그램 위에서도 동작하려면 서버도 관리자 권한으로 실행.

## 1-1. 윈도우 서브 PC (클라이언트)
- 메인 PC에서 만든 **`KVM-Client.exe` 하나만** 서브 PC로 옮겨 실행하면 됩니다. Python 설치 불필요.
- 설정 창이 열리면 같은 와이파이의 메인 PC가 **자동으로 목록에 나타나요** → 고르고 비밀번호 입력 → 저장하고 연결.
- "윈도우 시작 시 자동 실행"을 켜두면 PC를 켤 때마다 알아서 연결됩니다.
- 메인 PC에 새 버전이 생기면 **스스로 받아서 업데이트**하고 다시 켜집니다.
- 목록에 메인 PC가 안 보이면 메인 PC에서 `방화벽허용.bat`을 실행하세요.

## 2. 맥 (클라이언트)
```
pip3 install pyobjc-framework-Quartz pyobjc-framework-Cocoa pyperclip
python3 mac/client.py 192.168.x.x
```
- `client.py` 상단에서 `KEY`를 서버와 같게 맞추세요.
- 시스템 설정 → 개인정보 보호 및 보안 → **손쉬운 사용**에 터미널(또는 실행한 앱) 추가.
- 윈도우 Ctrl → 맥 Cmd로 바뀌어서 Ctrl+C/V가 그대로 복사/붙여넣기가 됩니다 (`SWAP_CTRL_CMD`).
- **윈도우 단축키가 맥의 같은 기능으로 바뀝니다** (끄려면 `SMART_SHORTCUTS = False`)
  Alt+Tab 앱 전환 · Alt+F4 앱 종료 · Win 검색(Spotlight) · Win+D 바탕화면 · Win+Tab Mission Control ·
  Win+E Finder · Win+L 잠금 · Win+Shift+S 영역 캡처 · PrtSc 전체 캡처 · Win+←/→/↑ 창 정렬 ·
  Ctrl+←/→ 단어 이동 · Ctrl+Backspace 단어 지우기 · Home/End 줄 처음/끝 · Ctrl+Y 다시 실행 · F5 새로 고침 ·
  Ctrl+Shift+Esc 활성 상태 보기 · 볼륨·재생 키. 전체 목록은 client.py의 SHORTCUT 표 참고.
- 서버에 새 버전이 생기면 연결될 때 **자동으로 업데이트**되고 다시 시작합니다.
- 한/영 키 → Ctrl+Space를 보냅니다. 맥에서 입력 소스 전환 단축키가 다르면 `HANGUL_TOGGLE` 수정.

## 3. 안드로이드 (클라이언트 앱)
1. PC에서 `apk만들기.bat` 실행 → KVM 폴더에 `KVM-Android.apk` 생성 (처음엔 빌드 도구를 내려받아 10~20분)
   이어서 `태블릿으로보내기.bat` → 화면에 나온 주소를 태블릿 Chrome에서 열고 내려받아 설치
   (설치 중 "출처를 알 수 없는 앱" 허용, Play 프로텍트 경고는 "무시하고 설치")
2. 앱에서 서버 IP·비밀번호 입력 → **저장하고 연결**.
3. 앱의 버튼 순서대로:
   - 접근성 → **PC 마우스 공유** 켜기 (커서 표시·탭·스크롤)
   - 키보드 목록 → **PC 키보드 공유** 켜기, 그리고 현재 키보드로 선택 (타이핑·한글 조합)

> APK 파일로 따로 설치했다면 안드로이드 13+에서 접근성 켜기가 막힐 수 있습니다.
> 앱 정보 → 오른쪽 위 ⋮ → **제한된 설정 허용** 후 다시 켜세요.

**조작법**: 왼쪽 클릭 = 탭 · 누른 채 끌기 = 드래그 · 오래 누르기 = 롱프레스 · 오른쪽 클릭/Esc = 뒤로 · 가운데 클릭 = 홈 · 휠 = 스크롤 · 한/영 = 한글 전환

## 업데이트 (패치)
새 버전은 `KVM-patch-버전.zip` 파일로 받습니다. **받기만 하면 끝이에요.**
- 서버가 켜져 있으면 **다운로드 폴더**(또는 KVM 폴더)에 생긴 패치를 몇 초 안에 찾아 자동으로 적용하고 다시 켜집니다.
  exe로 실행 중이면 새 exe를 자동으로 만들고(1~2분) 다시 켭니다. 진행 기록은 `kvm-update.log`.
- 설정 창의 "패치 자동 적용"을 끄면, 새 버전 알림만 뜨고 [업데이트] 버튼으로 적용합니다.
- 태블릿 앱이 바뀐 패치면 서버가 apk를 **자동으로 다시 빌드**하고 태블릿에 알립니다.
  태블릿에서는 알림이나 앱 화면의 **업데이트** 버튼만 누르면 설치돼요. (처음 한 번 '이 출처 허용' 필요)
- 맥 코드가 바뀐 패치면 설정 창에 안내가 뜹니다.
- 서버가 꺼져 있을 때는 zip을 `업데이트.bat` 위로 끌어다 놓거나 더블클릭.

`config.json`(비밀번호·배치)은 절대 덮어쓰지 않고, 덮어쓴 이전 파일은 `backup\날짜` 폴더에 남습니다.

## 클립보드
기기를 넘어갈 때 자동 동기화됩니다.
- 윈도우 ↔ 맥: 양방향
- 윈도우 → 안드로이드: 항상, 안드로이드 → 윈도우: 'PC 키보드 공유'가 현재 키보드일 때만 (안드로이드 보안 정책)

## 알려진 한계 (프로토타입)
- 안드로이드는 진짜 마우스가 아니라 **터치 흉내**라서, 드래그는 버튼을 뗀 순간 한 번에 재생됩니다 (끄는 동안 실시간으로 보이지 않음).
- 윈도우 커서는 원격 조작 중 화면 가운데에 멈춰 있습니다.
- 윈도우 모니터가 여러 대면 전체를 감싸는 하나의 사각형으로 취급합니다. 맥은 메인 디스플레이 기준. 기기끼리(맥↔안드로이드) 직접 이동은 안 되고 윈도우를 거쳐야 합니다.
- Ctrl+Alt+Del은 가로챌 수 없습니다.

## 구조
```
업데이트.bat        패치 zip 적용 (tools/apply_patch.ps1)
windows/server.py   마우스·키보드 훅 → TCP(JSON 한 줄씩) 전송, 드래그 배치 창(tkinter), 트레이(pystray)
mac/client.py       Quartz CGEvent로 재현, Windows 키코드 → 맥 키코드 변환
android/            접근성 서비스(커서·제스처) + 입력기(키 입력·두벌식 한글 조합)
```
메시지: `enter/leave/move{x,y}`, `btn{b,d}`, `wheel{dx,dy}`, `key{vk,d}`, `clip{text}`, `hello/size`
